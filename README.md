# ResXR Website

Source for the **ResXR** landing page, live at **[resxr.org](https://resxr.org)**.

ResXR is an open-source, end-to-end toolkit for conducting behavioral XR
experiments on Meta Quest standalone headsets and exporting Motion-BIDS-compliant
data.

This is a static site (`index.html` + `index.css`) deployed to GitHub Pages.
